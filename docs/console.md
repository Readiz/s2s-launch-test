# PC A S Box 콘솔 요구사항

PC A는 전체화면 브라우저로 가상 콘솔 **S Box**를 재현한다. 홈에는 Apex Racing, Forest Quest, Orbit Arena의 이미지와 아이콘을 표시한다. 내부 식별자와 기존 딥링크 app ID는 유지하며 화면과 WGT 이름에는 게임 이름을 사용한다.

## 시작 화면

브라우저 접속과 새로고침마다 약 **2.4초** 동안 S Box 로고, 이름, 진행 막대를 보여준 뒤 화면을 연다. 로고는 부팅 화면과 상단 홈 링크, 홈의 브라우저 아이콘에 사용한다. 부팅 중에는 홈 조작부를 숨기고 게임 실행 키 입력을 받지 않는다.

SSE는 부팅 중에도 연결해 명령을 받는다. 여러 요청이 들어오면 마지막 앱 상태만 남기고 부팅이 끝난 뒤 게임 로딩을 시작한다. 마지막 상태가 홈이면 라이브러리를 연다. B 연결 여부와 관계없이 부팅 효과는 끝나므로 로컬 조작을 계속 사용할 수 있다. 실제 하드웨어 부팅이나 네트워크 연결 진행률을 나타내는 화면은 아니다.

## 홈과 타이틀 화면

- 홈에서 선택한 게임의 큰 이미지와 이름, 설명을 표시한다. 아래 세 게임 카드에는 각각 배경 이미지와 아이콘을 표시한다.
- 선택한 게임의 배경은 0.5초 크로스페이드로 바뀐다. 카드에는 이미지 확대와 빛 반사 효과를 적용하며, 연속 선택 시 이전 전환을 취소해 마지막 선택을 유지한다.
- 로컬 실행과 B의 원격 명령 모두 같은 흐름을 따른다. 약 **2.2초의 모의 로딩 → 게임별 타이틀 메뉴** 순서다.
- 로딩 화면에는 게임 아이콘, 이름, 준비 문구와 진행 막대가 나온다. 실제 게임 데이터 다운로드 진행률은 아니다.
- Apex Racing은 레이싱, Forest Quest는 판타지 모험, Orbit Arena는 우주 아레나 테마의 배경과 타이포그래피를 사용한다.
- 게임 실행 시 로딩부터 타이틀까지 브라우저 영역 전체를 채운다. 콘솔 상단 바·하단 안내·바깥 여백과 좌상단 뒤로 버튼은 표시하지 않는다.
- 홈에서 직접 클릭이나 Enter로 게임을 실행하면 브라우저 전체화면도 요청한다. 브라우저가 이를 허용하지 않더라도 게임 화면은 전체 뷰포트를 사용한다. 원격 딥링크에는 사용자 입력 권한이 없으므로 브라우저 자체의 전체화면은 미리 F11 또는 홈의 전체화면 버튼으로 켠다.
- 타이틀에는 게임별 시작 메뉴, 설정, **게임 종료**가 있다. 게임 종료는 S Box 라이브러리로 돌아온다. 배경 확대와 밝기 전환 뒤 타이틀과 메뉴가 순서대로 나타난다. 시작 메뉴는 해당 게임의 준비 장면 안내를 보여준다. 실제 플레이 가능한 게임 본체는 포함하지 않는다.
- 설정의 화면 전환 효과를 끄면 현재 브라우저의 CSS 애니메이션과 배경 크로스페이드를 생략한다. 이 설정은 새로고침하면 기본값으로 돌아온다. OS의 reduced motion 설정은 부팅부터 적용하며 실행 중 변경도 따른다. 부팅 2.4초와 게임 로딩 2.2초의 모의 대기 시간은 유지한다.

로딩 중 다른 게임 명령을 받으면 이전 타이머를 취소하고 새 게임을 로딩한다. 늦게 실행된 이전 콜백이 최신 게임을 덮어쓰지 않는다. 같은 게임을 다시 실행해도 로딩부터 시작한다. 로딩 중 홈으로 돌아가면 과거 타이머가 게임을 다시 열지 않는다.

## 입력

| 위치와 입력 | 동작 |
|---|---|
| 홈에서 ←/↑, →/↓ | 이전/다음 게임 선택, 처음과 끝에서 순환 |
| 홈에서 Enter 또는 게임 클릭 | 선택한 게임 실행 |
| 홈의 상단 S Box 로고 | 게임 라이브러리 표시 |
| 게임 메뉴의 게임 종료 | 게임을 닫고 해당 A의 라이브러리 표시 |
| 게임 또는 로딩 중 Esc | 게임을 닫고 해당 A의 라이브러리 표시 |
| 타이틀에서 ↑/↓ | 게임 메뉴 사이 포커스 이동 |
| 타이틀에서 Enter | 포커스한 메뉴 실행 |
| 대화상자에서 Esc | 대화상자만 닫고 타이틀 유지 |
| Tab | 조작 요소 사이 포커스 이동 |
| F11 또는 전체화면 버튼 | 전체화면 전환 |

전체화면이나 다른 버튼에 포커스가 있으면 Enter는 그 버튼을 작동시킨다. 게임 종료 후에는 방금 실행한 게임을 선택한 상태로 돌아온다. 게임 실행으로 브라우저 전체화면을 켠 경우, 브라우저가 Esc를 먼저 처리해 전체화면을 해제해도 게임은 종료된다.

## 통신과 상태

A는 B에 WebSocket으로 연결한다. B로 보낸 요청은 그때 연결된 모든 A의 화면을 전환한다. 로컬 키보드 조작과 홈 복귀는 해당 A만 변경한다. A의 여러 브라우저는 SSE로 같은 앱 상태를 받지만 각 브라우저의 로딩 애니메이션과 메뉴 선택은 독립적으로 표시한다.

B가 꺼져 있어도 A의 로컬 실행과 홈 복귀는 가능하다. 현재 앱은 A 서버 메모리에 저장한다. 브라우저를 다시 열거나 새로 고치면 S Box 부팅 후 현재 게임을 로딩해 표시하고, A 서버를 재시작하면 부팅 후 홈을 연다. B는 재연결한 A에 과거 명령을 재생하지 않는다.

B의 성공 응답은 A 서버가 브라우저에 전환 이벤트를 전달했다는 의미다. 모의 로딩이나 실제 렌더링, HDMI 입력 전환 완료를 확인하는 응답은 아니다.

## 이미지와 아이콘

`assets/games/`에 게임별 `cover.webp`, 콘솔용 `icon.png`, WGT 개발 설치용 `icon-117.png`를 둔다. 이미지들은 저장소 안에서 제공하며 외부 이미지 서버에 의존하지 않는다. 생성 프롬프트와 자산 구성은 [이미지 안내](../assets/games/README.md)에 정리한다.

`assets/brand/s-box.svg`는 S Box의 벡터 로고다. WGT에는 S Box 로고 대신 각 게임의 설치 아이콘을 사용한다.

## 확인 기준

1. 세 게임의 이미지와 이름, 서로 다른 아이콘을 확인한다.
2. 키보드와 HTTP 딥링크 각각에서 로딩 후 올바른 타이틀이 나타나는지 확인한다.
3. 여러 A를 연결하고 같은 요청으로 모두 전환되는지 확인한다.
4. 로딩 중 연속 딥링크를 보내 마지막 게임만 남는지 확인한다.
5. 로딩 도중 Esc로 복귀하고 이전 타이머가 화면을 다시 열지 않는지 확인한다.
6. 타이틀의 시작, 설정, 홈 메뉴와 대화상자 Esc를 확인한다.
7. PC, 태블릿, 좁은 모바일 폭에서 가로 넘침과 조작부 겹침이 없는지 확인한다.
8. WGT의 이름과 `icon.png`가 각 게임에 맞게 패키징되는지 확인한다.
9. 새로고침 시 부팅 화면을 확인하고, 부팅 중 연속 명령과 홈 복귀에서 마지막 상태만 표시되는지 확인한다.
10. 빠른 카드 선택, 게임 전환, 효과 끄기와 OS의 동작 줄이기 설정에서 잔상이나 이전 선택이 남지 않는지 확인한다.
