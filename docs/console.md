# PC A 콘솔 요구사항

PC A는 HDMI로 TV와 연결된 콘솔을 대신합니다. 서버와 브라우저는 PC A에서 실행합니다.

## 화면

- 서버를 처음 켜고 콘솔 페이지에 접속하면 A/B/C게임이 있는 홈을 표시합니다.
- 선택된 앱은 테두리와 키보드 포커스로 구분합니다.
- 앱을 실행하면 해당 게임 이름, 식별자, 테마를 가진 데모 화면을 표시합니다.
- 게임 화면에는 홈 복귀 버튼을 둡니다.
- 게임 중 다른 앱의 딥링크를 받으면 새 앱 화면으로 전환합니다.

실제 게임 프로세스를 실행하는 것이 아니라 브라우저에서 콘솔 동작을 시연합니다.

## 입력

| 입력 | 동작 |
|---|---|
| ← / ↑ | 이전 앱 선택 |
| → / ↓ | 다음 앱 선택 |
| Enter | 선택한 앱 실행 |
| 게임 클릭 | 클릭한 앱 실행 |
| Esc / 홈 버튼 | 콘솔 홈으로 복귀 |
| Tab | 조작 요소 사이 포커스 이동 |
| F11 / 전체화면 버튼 | 전체화면 전환 |

방향키 선택은 처음과 끝에서 순환합니다. 전체화면 버튼에 포커스가 있으면 Enter는 해당 버튼을 작동시킵니다.

## 로컬 실행과 딥링크

로컬 입력은 PC A의 `POST /launch`를 직접 호출합니다. **PC B가 꺼져 있어도 콘솔에서 직접 앱을 실행할 수 있습니다.** TV나 향후 PC C의 요청은 PC B가 WebSocket으로 현재 연결된 모든 PC A에 같은 앱 ID를 전달합니다. PC A는 먼저 B에 연결하며 자신의 IP를 B에 등록하지 않습니다. 두 경로 모두 같은 콘솔 상태를 갱신합니다.

홈 복귀는 PC A의 `POST /home`으로 처리합니다. 브라우저는 `/events`를 통해 변경 내용을 받습니다. 같은 A에서 여러 표시 창을 열면 같은 화면으로 맞춰집니다. 키보드 조작과 홈 복귀는 해당 A만 바꾸고 다른 A에는 전송하지 않습니다.

현재 앱은 PC A 서버 메모리에 보관합니다. 브라우저를 새로 고치면 현재 화면을 복원하고, 서버를 다시 시작하면 홈으로 돌아갑니다.

## 확인 기준

1. 초기 홈에서 세 게임이 보입니다.
2. 방향키, Enter로 A/B/C게임을 각각 실행합니다.
3. Esc로 홈에 돌아오면 방금 실행한 앱이 선택됩니다.
4. PC B를 통한 딥링크도 같은 게임 화면을 엽니다.
5. 게임 중 다른 딥링크를 받으면 해당 게임으로 바뀝니다.
6. PC B 없이도 로컬 실행과 홈 복귀가 동작합니다.
